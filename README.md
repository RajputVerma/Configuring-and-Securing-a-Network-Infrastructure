Configuring and Securing a Network Infrastructure
Minor Project – Cyber Security
📌 Project Overview

This project demonstrates the design and implementation of a secure small-scale enterprise network in a virtual lab environment. The network was configured using Cisco Packet Tracer and tested using Windows and Kali Linux.

Security mechanisms such as VLAN segmentation, Access Control Lists (ACLs), Quality of Service (QoS), and Secure Shell (SSH) were implemented to enhance performance and protect network resources.

🎯 Objectives

Design a basic enterprise network topology

Implement VLAN-based network segmentation

Configure firewall rules using ACL

Apply QoS for traffic prioritization

Enable secure remote management using SSH

Test and validate network security

🛠 Tools and Technologies Used

Cisco Packet Tracer

Cisco Router (2911)

Cisco Switch (2960)

Windows OS

Kali Linux Virtual Machine

Nmap

Wireshark

🌐 Network Design
IP Addressing

Router: 192.168.10.1 /24

PC1: 192.168.10.10

PC2: 192.168.10.11

VLAN Configuration

VLAN 10 – STAFF

VLAN 20 – ADMIN

🔐 Security Implementation

Access Control List (ACL) configured to filter unauthorized traffic

SSH enabled for encrypted remote access

Local user authentication configured

QoS policy applied for prioritizing important traffic

🧪 Testing and Validation

ICMP Ping tests for connectivity

Nmap scanning for network discovery

Wireshark for traffic monitoring

Windows firewall rule validation

Interface verification using CLI commands

📊 Results

The network was successfully configured and secured. VLAN segmentation improved organization, ACL restricted unauthorized access, and SSH ensured secure device management. The network performed reliably during testing.
